# 2027 그룹 인재육성 체계 수립 - 구성원 교육 Needs 설문조사 전용 웹 서비스

## 📌 시스템 개요
본 프로젝트는 **일반 구성원(응답자) 전용으로 독립 구축된 설문조사 웹 서비스**입니다.  
관리자용 대시보드(2번 결과분석, 3번 인재육성전략, 엑셀/PPTX 다운로드 등) 코드가 일체 배제되어 있어, 구성원에게 안전하고 쾌적한 설문 환경을 제공합니다.

---

## 🚀 빠른 실행 방법
1. 본 폴더(`c:\실습\DEV\2027 구성원 교육니즈 설문조사`)의 **`run_server.bat`** 파일을 더블클릭합니다.
2. 기본 브라우저에서 `http://localhost:5001` 주소로 구성원 전용 설문조사 화면이 자동으로 열립니다.

---

## 🔗 관리자 대시보드 실시간 연동
- 구성원이 작성한 **29개 문항 응답 데이터**와 **스타벅스 커피쿠폰 이벤트 응모 전화번호**는  
  관리자 프로젝트(`c:\실습\DEV\구성원 교육니즈 설문\data\`)에 실시간으로 자동 동기화 저장됩니다.
- HR 관리자는 기존 관리자 대시보드(`http://localhost:5000`)에서 **실시간 응답 현황 차트 분석** 및 **엑셀(Excel) 다운로드**를 그대로 이용하실 수 있습니다.

---

## 🎁 포함된 기능
- 29개 설문 문항 반응형 렌더링 (소속 법인 및 부문 콤보 상자, 5점 척도, 다중선택 등)
- 100% 익명성 보장 보안 뱃지
- 설문 제출 즉시 **부캉이 스타벅스 럭키드로우 이벤트 게임 모달** 자동 실행
- 휴대전화 번호 1인 1회 응모 중복 제한
- 상어가족 BGM 및 부캉이 흥국금융 골인 애니메이션
- 완료 후 **`✕ 창 닫기 (화면 종료)`** 안전 종료 기능
